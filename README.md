# Atelier fonts

The typefaces the Atelier app downloads the first time one is used, rather
than bundling them all. Each folder is a family, under the license next to
its fonts (the SIL Open Font License, or the Apache License): a font is
named for what is in it, so a changed font is a new file, and the files
apps already installed ask for stay.

Free fonts are cut down to the letters, marks and symbols of Persian and of
the languages written in Latin letters, without hinting; those whose
license reserves their name are as their authors publish them.

Written by tool/fonts/build.py --publish; do not edit by hand.
